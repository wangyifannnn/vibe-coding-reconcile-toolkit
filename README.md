# 订单退款对账工具

## 使用方法

1. 将订单 CSV 和退款 CSV 放入 `input` 文件夹。
2. 双击 `运行程序.bat`。
3. 在 `output` 文件夹查看 `reconciliation_result.xlsx`。

首次运行会自动安装所需组件，需要保持网络连接。之后可直接运行。

## 输入字段

- 订单表：订单号、客户手机、支付金额、下单时间、收货地址
- 退款表：原订单号、退款金额（其他字段可以保留）

文件名可以更改，但每类 CSV 在 `input` 中只能有一个。

## 输出内容

- `Cleaned_Orders`：清洗、去重并关联退款后的有效订单
- `Anomaly_Log`：金额缺失、地址缺失或手机号异常的原始订单及原因

同一订单号重复出现时保留第一条。原始输入文件不会被修改。
